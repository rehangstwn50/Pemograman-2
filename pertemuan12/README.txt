Nama project: pertemuan12

Cara menjalankan di NetBeans:
1. Extract file pertemuan12.zip.
2. Buka NetBeans.
3. Pilih File > Open Project.
4. Pilih folder pertemuan12.
5. Jalankan dengan Apache Tomcat 9.

URL utama:
http://localhost:8080/pertemuan12/

URL servlet:
http://localhost:8080/pertemuan12/MenghitungNilai

Catatan:
Project ini memakai javax.servlet-api sehingga cocok untuk Tomcat 9.
Jika memakai Tomcat 10, package perlu diganti ke jakarta.servlet.
